# Networkwalks-B082-week1-Cybersecurity-lab-setup
Cybersecurity Home Lab
Overview
I built a personal cybersecurity lab using VirtualBox and Kali Linux to develop practical skills in cybersecurity, networking, and security testing.
Completed Steps
1. 7-Zip Installation
Installed 7-Zip to extract and manage virtual machine files.
2. VirtualBox Installation
Installed Oracle VirtualBox as the virtualization platform.
3. Network Configuration
Created a VirtualBox NAT Network using: 10.0.0.0/24
This provides an isolated network environment for the virtual machines.
4. Kali Linux VM
Downloaded and imported Kali Linux into VirtualBox.
5. Kali Linux Network Configuration
Configured the Kali Linux IP settings and connected it to the lab network.
